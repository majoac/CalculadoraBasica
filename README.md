# **CalculadoraBasica**
Creadora: Maria Jose Arevalo

● Descripción: Este proyecto consistió en la creación de una aplicación de escritorio funcional desarrollada durante el primer semestre para la materia de Desarrollo de Sistemas I. El sistema fue programado desde cero en lenguaje Java utilizando NetBeans como entorno de desarrollo (IDE). Cuenta con una interfaz gráfica de usuario simple que incluye una pantalla principal para visualizar las operaciones matemáticas. Su diseño incorpora un teclado numérico completo con punto decimal, botones para ejecutar las cuatro operaciones aritméticas básicas (división, multiplicación, resta y suma), la tecla de cálculo de resultado (=) y un comando de borrado (CE) para reiniciar la pantalla.
